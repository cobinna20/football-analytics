# Football Analytics

My football prediction app.

It looks at football stats and tries to guess the score.

## What is inside
- backend = the brain, it does the maths
- frontend = the face, what you see on screen

## How to run it later on a laptop
Backend: cd backend, pip install -r requirements.txt, uvicorn app.main:app --reload --port 8000
Frontend: cd frontend, npm install, npm run dev
